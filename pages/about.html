About Synapse

Synapse is an interactive educational platform built to visualize, compare and understand algorithms used in Computational Foundations of Artificial Intelligence.

Project Purpose

To provide students with an intuitive way to learn sorting, searching and graph search algorithms through visualizations and comparisons.

Technologies Used

  • HTML5
  • CSS3
  • JavaScript

Features

  • Sorting Visualizer
  • Graph Search Visualizer
  • Searching Algorithms
  • Performance Comparison
  • Algorithm Library

Algorithms Included

  • Bubble Sort
  • Selection Sort
  • Insertion Sort
  • Merge Sort
  • Quick Sort
  • BFS
  • DFS
  • UCS
  • Greedy Search
  • A*
  • Linear Search
  • Binary Search

Academic Project

Developed for Computational Foundations of Artificial Intelligence (CFAI).
