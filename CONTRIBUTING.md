# Contributing to Synapse

Thanks for your interest in contributing to Synapse! ??

Synapse is an interactive algorithm visualization studio built with HTML, CSS, and vanilla JavaScript.

## Getting Started

1. Fork the repository.
2. Clone your fork locally.
3. Open the project in your preferred editor.
4. Open index.html in a browser or use a local development server.
5. Make your changes and test them locally.

## Project Structure

```text
Synapse_Studio/
+-- assets/             # Images and visual assets
+-- css/                # Stylesheets
+-- docs/screenshots/   # Project screenshots and demo media
+-- js/                 # Application logic
+-- pages/              # Application pages
+-- .github/workflows/  # GitHub Actions validation
+-- index.html          # Main dashboard
+-- README.md
+-- LICENSE
```

## Making Changes

- Keep changes focused and relevant.
- Follow the existing project structure and coding style.
- Avoid adding unnecessary dependencies.
- Test interactive features in the browser before submitting changes.
- Do not commit temporary files, debug output, or editor-specific files.

## Pull Requests

Before opening a pull request:

- Make sure the project works locally.
- Check that your changes do not introduce console errors.
- Ensure existing functionality still works.
- Write a clear pull request title and description.
- Keep each pull request focused on one improvement or fix.

## Issues

If you find a bug or have an improvement idea, open an issue with:

- A clear description of the problem or idea
- Steps to reproduce the issue, when applicable
- Expected behavior
- Actual behavior
- Screenshots or additional context when useful

## Code of Conduct

Please keep discussions and contributions respectful, constructive, and focused on improving the project.
